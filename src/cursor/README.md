# cursor/ — one cursor, three units, carried by commit index

Every tab reads and moves the SAME position. Flow scrubs the commit axis
(every executed stage), Why scrubs the milestone axis (the agent's own
moments), the Skill Graph rides the routing stops — and the viewer carries
the position between them by the one unit all of them share: the commit
index (`stepForCommitIdx`, the lens 0.39 mechanism, imported not forked).
Switching tabs keeps your place, always; there is no setting that breaks
this. The Story player keeps its own transport by design — its beats are a
narration, not a step count.
